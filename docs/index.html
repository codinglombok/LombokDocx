LombokDocx

DOCX → HTML content extractor — text, images, tables, and formatting, zero-dependency.

Install

npm install lombokdocx

DOCX unzip + parse

Reads the OOXML ZIP structure natively.

Style preservation

Fonts, colors, bold/italic, alignment.

Table extraction

Convert Word tables to semantic HTML.

Image extraction

Pull embedded images out of the archive.

Metadata

Document core properties (title, author, dates).

HTML output

Clean semantic HTML ready for PDF injection.

Quick start

import { Docx } from 'lombokdocx'

const docx = new Docx(docxBuffer)
docx.extract()

const html   = docx.getHTML()
const images = docx.getImages()
const tables = docx.getTables()
const meta   = docx.getMetadata()
